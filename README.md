# scripts

Useful scripts for one-off jobs that might come in handy at a later date.

## Contents

### [gmail-cleanup](gmail-cleanup/README.md)
Permanently deletes old emails from Gmail using the Gmail API. Targets read inbox/archive emails and sent emails independently, each with a configurable age threshold. Supports dry-run mode and exempts starred emails.

### [remove-empty-folders](remove-empty-folders/README.md)
A PowerShell script that recursively scans a directory and deletes any empty folders found within. Supports a `-WhatIf` dry-run flag.
